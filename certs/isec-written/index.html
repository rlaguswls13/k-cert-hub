과목 (공식 출제영역) 수록 문항 비중 기출복원 학습은행 내 풀이수 정답 / 정확도 과락 판정 (40점+)

1과목 · 시스템 보안 핵심

  • 특수권한: 4755 SetUID(-rws), 2755 SetGID(-r-s), 1777 Sticky Bit(t)
  • PAM 계정잠금: 구형 pam_tally2 → 최신 RHEL8+/Ubuntu pam_faillock.so (preauth/authfail)
  • 메모리 보호: ASLR(주소 난수화, randomize_va_space), DEP/NX(스택 실행금지), Stack Canary
  • Windows 보안: Security.evtx Event ID 4624(성공)/4625(실패)/4720(계정생성)/1102(로그삭제), Credential Guard

2과목 · 네트워크 보안 핵심

  • 포트 스캔: SYN/Connect(열림 SYN/ACK), FIN/NULL/Xmas(닫힘 RST), ACK(필터링 미적용 RST)
  • L2/L3 보안: DHCP Snooping + DAI(ARP Spoofing 차단), BGP RPKI/ROA(경로 탈취 검증)
  • IPsec VPN: 3계층 보안, AH(인증·무결성) vs ESP(기밀성·무결성·인증), Transport(호스트) vs Tunnel(게이트웨이)
  • 차세대 관제·무선: WPA3 SAE(전방향 비밀성), Zero Trust(NIST SP 800-207) PDP/PEP, SIEM+SOAR

3과목 · 애플리케이션 보안 핵심

  • 웹 5대 취약점: SQLi(PreparedStatement), XSS(인코딩·CSP·HttpOnly), CSRF(SameSite·토큰), SSRF(내부IP/IMDS 차단), XXE(DTD 비활성화)
  • 파일·API: BOLA/IDOR(객체 소유권 검증), 파일업로드(화이트리스트+웹루트 외부저장+UUID), Log4Shell(JNDI Lookup)
  • 메일·DNS·웹서버: SPF/DKIM/DMARC, allow-transfer(AXFR 차단), vsftpd.conf, Nginx server_tokens off

4과목 · 암호학 & 정보보안 일반

  • 블록암호·공개키: AES-GCM(CTR+GHASH AEAD), RSA(소인수분해), ECC(짧은 키 길이), PQC(ML-KEM/ML-DSA)
  • 해시·인증: 역상/제2역상/충돌 저항성(생일공격 2^(n/2)), HMAC, Kerberos(AS→TGT→TGS→ST 대칭키)
  • 접근통제·포렌식: BLP(No Read Up / No Write Down) vs Biba(No Read Down / No Write Up), 포렌식 Chain of Custody

5과목 · 관리 및 법규 (2023~2026 개정)

  • 개인정보 유출 통지·신고: 인지 후 72시간 이내 통지 및 신고(1,000명 이상·민감/고유식별 등)
  • 망법 침해사고 신고: 침해사고 인지 후 24시간 이내 KISA/과기정통부 최초 신고(제48조의3)
  • 접속기록·ISMS-P: 접속기록 1년(대규모·민감 2년) 이상 보관 & 월 1회 점검, ISMS-P 유효 3년(연 1회 사후)
  • 신규 제도: 자동화된 결정 거부·설명요구권(제37조의2), CSAP 상·중·하 등급제, 국가 망 보안체계 N2SF (C·S·O)
