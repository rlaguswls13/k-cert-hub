SQLD 2024 개정 출제기준 과목·단원별 문항 분포 분석 (총 110문항)
세부 출제 단원 소속 과목 문항 수 비중 객관식 4지선다 주관식 단답형 바로가기

1. 1과목 모델링 · 정규화 · ERD 핵심

  • 모델링 3특징: 추상화, 단순화, 명확화 | 3요소: Things, Attributes, Relationships
  • 정규화 두문자 (도·부·이·결·다·조): 1NF(원자값) → 2NF(부분 종속 제거) → 3NF(이행 종속 제거) → BCNF(모든 결정자가 후보키)
  • ERD 표기 비교: IE(실선=식별, 점선=비식별, 원 O=선택) vs Barker(실선=필수, 점선=선택, UID Bar |=식별)
  • 슈퍼/서브타입 물리변환: One-to-One(개별) / Plus(슈퍼+서브) / Single(All-in-One 통합)
  • 무결성 유지 반정규화: 중복 관계 추가 (테이블/컬럼 중복은 무결성 훼손 주의)

2. SQL 실행순서 · NULL · 관리구문

  • 논리 실행순서: FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY
  • CHAR vs VARCHAR: CHAR는 뒤 공백 무시(앞 공백 엄격), VARCHAR는 모든 공백 엄격 비교
  • NULL 규칙: 산술연산 결과 NULL, 비교연산 UNKNOWN, 집계함수(SUM/COUNT/AVG)는 NULL 제외
  • DELETE / TRUNCATE / DROP: DELETE(DML, 일부 가능, 롤백 O) / TRUNCATE(DDL, 전체만, 롤백 X) / DROP(DDL, 구조+데이터 삭제)
  • DCL 중간권한: WITH GRANT OPTION(오브젝트, 연쇄 회수 O) vs WITH ADMIN OPTION(시스템/롤, 연쇄 회수 X)

3. JOIN · 서브쿼리 · 윈도우 · 계층형

  • OUTER JOIN 주의: 오른쪽 테이블 필터 조건은 WHERE가 아닌 ON 절에 두어야 기준 행 보존
  • NOT IN 함정: 서브쿼리에 NULL 포함 시 0건 반환 → IS NOT NULL 추가 또는 NOT EXISTS 사용
  • 그룹함수: ROLLUP(A,B)(순서 중요, N+1 레벨) / CUBE(A,B)(2^N, 순서 무관) / GROUPING SETS(A,B)(총계 없음, () 필요)
  • 윈도우 프레임: ORDER BY만 쓰면 기본 RANGE(동점자 동시 합산) → 행별 누적은 ROWS 명시! LAST_VALUE는 UNBOUNDED FOLLOWING 필수
  • 계층형 순방향: START WITH 루트조건 CONNECT BY PRIOR 자식키 = 부모참조키 (ORDER SIBLINGS BY)

4. 2024 신유형 (Top-N · PIVOT · REGEXP)

-- 1) Top-N 페이징 (Oracle 12c+ / SQL Server)
SELECT * FROM EMP
ORDER BY SAL DESC
OFFSET 5 ROWS FETCH NEXT 3 ROWS ONLY; -- WITH TIES 가능

-- 2) PIVOT / UNPIVOT
SELECT * FROM (SELECT JOB, DEPTNO, EMPNO FROM EMP)
PIVOT (COUNT(EMPNO) FOR DEPTNO IN (10, 20, 30));

SELECT * FROM TEST1
UNPIVOT (CNT FOR DEPTNO IN ("10", "20", "30"));
  • 정규식 5대 함수: REGEXP_LIKE(WHERE 조건), REGEXP_REPLACE(치환), REGEXP_SUBSTR(추출, 6번째=추출그룹), REGEXP_INSTR(위치), REGEXP_COUNT(횟수)
  • 제외된 구범위 주의: 2024 개정부터 PL/SQL(프로시저/트리거) 및 옵티마이저/인덱스·조인 튜닝 원리는 SQLD 출제에서 제외됨
