1. Snort IDS 룰 핵심 문법

alert tcp any any -> 192.168.1.0/24 80 \
  (msg:"Attack"; content:"UNION"; nocase; \
   flags:S; threshold:type limit, track by_src, \
   count 10, seconds 60; sid:1000001; rev:1;)
  • 액션: alert(경고+로그), log, pass, drop(IPS 차단)
  • threshold 유형: limit(최초 N회만), threshold(매 N회마다), both(N회 도달 시 1회)
  • 페이로드 옵션: content, nocase, offset, depth, pcre

2. iptables & Cisco ACL 방화벽 실무

# iptables 기본 DROP + 상태기반 + SSH 허용
iptables -P INPUT DROP
iptables -A INPUT -m state --state ESTABLISHED,RELATED -j ACCEPT
iptables -A INPUT -p tcp -s 192.168.10.0/24 --dport 22 -j ACCEPT

# Cisco 확장 ACL (100~199, 와일드카드 마스크)
access-list 100 permit tcp 192.168.10.0 0.0.0.255 any eq 443
access-list 100 deny ip any any
  • 체인: INPUT(수신), OUTPUT(송신), FORWARD(경유)
  • 타겟: ACCEPT(허용), DROP(무응답 폐기), REJECT(오류 응답 후 거부)

3. Linux 보안 설정 · 로그 · 특수권한

  • 쉐도우 해시 식별자: $1$ MD5 / $5$ SHA-256 / $6$ SHA-512
  • 패스워드 정책: /etc/login.defs (PASS_MIN_LEN, PASS_MAX_DAYS)
  • SSH 루트 차단: /etc/ssh/sshd_config → PermitRootLogin no
  • PAM 4대 모듈: auth(인증), account(계정검증), password(암호변경), session(세션환경)
  • 특수권한 검색: find / -user root -perm -4000 -type f 2>/dev/null
  • 핵심 로그: wtmp(last), btmp(lastb), utmp(who), lastlog(lastlog), secure(인증 텍스트)

4. 개인정보보호법 · ISMS-P 필수 기준치

  • 비밀번호 저장: 복호화 불가 일방향 해시 암호화 (전송 시 구간 암호화 TLS)
  • 접속기록 보관: 일반 1년 이상 / 5만명·고유식별·민감정보 2년 이상
  • 접속기록 점검: 월 1회 이상 정기 확인·감독
  • ISMS-P 인증 기준: 총 101개 (관리체계 16 + 보호대책 63 + 개인정보 22), 유효기간 3년
  • 침해사고 최초 신고: 인지한 때로부터 24시간 이내 (KISA/과기정통부)
  • PIA 의무 대상(공공): 5만명(민감/고유식별), 50만명(연계), 100만명(단일 파일)
