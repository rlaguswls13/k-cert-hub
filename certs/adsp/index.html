1과목 · 데이터 이해 핵심 요약

  • DIKW 피라미드: Data(객관적 사실) → Information(가공·패턴/의미) → Knowledge(패턴 이해·예측) → Wisdom(근본 원리·창의적 아이디어)
  • SECI 지식 전환: 공통화(암→암) → 표출화(암→형) → 연결화(형→형) → 내면화(형→암)
  • DW 4대 특성: 주제지향성, 통합성, 시계열성, 비휘발성(비소멸성)
  • 빅데이터 본질 변화: 사전→사후처리, 표본→전수조사, 질→양, 인과→상관관계
  • 위기요인 통제: 사생활 침해(동의제→책임제) / 책임훼손(결과기반 강화) / 오용(알고리즘 접근·인증)
  • 비식별화: 가명처리(대체), 총계처리(합/평균), 삭제, 범주화(대푯값), 마스킹(* 기호 가림)

2과목 · 데이터 분석 기획 핵심 요약

  • 분석 주제 4유형: Optimization(대상○·방법○) / Solution(대상○·방법×) / Insight(대상×·방법○) / Discovery(대상×·방법×)
  • KDD 5단계: 데이터셋 선택 → 전처리 → 변환 → 데이터 마이닝 → 결과 평가
  • CRISP-DM 6단계: 업무 이해 → 데이터 이해 → 데이터 준비 → 모델링 → 평가 → 전개 (4레벨 계층)
  • 빅데이터 분석 방법론: 분석기획 → 데이터준비 → 데이터분석 → 시스템구현 → 평가및전개 (Phase-Task-Step)
  • 하향식 접근 4단계: 문제 탐색 → 문제 정의 → 해결방안 탐색 → 타당성 검토(경제·데이터·기술)
  • 우선순위 사분면: 시급성(전략적 중요도·목표가치) vs 난이도(비용·분석 수준)

3과목 · R 기초 · 전처리 · 기초통계

  • R 벡터 형변환: character > numeric > logical (문자 포함 시 전체 문자형)
  • R 데이터 마트: reshape(melt/cast), plyr(ddply), sqldf(SQL 질의)
  • 이상치 판별: ESD(평균 ± 3σ), IQR(Q1 - 1.5*IQR ~ Q3 + 1.5*IQR 밖)
  • 왜도와 대푯값: Positive Skewed(오른쪽 긴 꼬리) → 최빈값 < 중앙값 < 평균
  • 척도 4종: 명목(분류) < 서열(순위, 스피어만) < 등간(간격·절대0 없음) < 비율(절대0 있음·사칙연산)
  • 가설검정 오류: 제1종 오류(H0 참인데 기각, 유의수준 α) / 제2종 오류(H0 거짓인데 채택, β)

3과목 · 회귀 · 시계열 · 마이닝 공식

  • 다중공선성: VIF ≥ 10이면 심각 (해결: 변수 제거, PCA, Ridge)
  • 회귀 규제화: Lasso(L1 페널티, 계수 0→변수선택) / Ridge(L2 페널티, 계수 축소)
  • 시계열 정상성: 일정한 평균·분산 + 시차에만 의존하는 공분산 (추세 제거 = 차분)
  • 의사결정나무 불순도: CART(지니지수 1-Σp²), C4.5/C5.0(엔트로피), CHAID(카이제곱)
  • 오분류표 지표: 정밀도=TP/(TP+FP), 재현율(민감도)=TP/(TP+FN), 특이도=TN/(FP+TN), F1=2PR/(P+R)
  • 연관분석 지표: 지지도=P(A∩B), 신뢰도=P(A∩B)/P(A), 향상도=신뢰도/P(B)
