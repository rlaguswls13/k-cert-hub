1. Domain 1 · 클라우드 개념 (24%)

  • 클라우드 6대 이점: CapEx→OpEx 전환, 규모의 경제, 용량 예측 불필요(탄력성), 속도·민첩성, 데이터 센터 운영 비용 절감, 수분 내 전 세계 배포.
  • Well-Architected 6대 원칙: 운영 우수성 · 보안 · 안정성 · 성능 효율성 · 비용 최적화 · 지속 가능성.
  • 아키텍처 핵심: 느슨한 결합(Loose Coupling), 단일 장애점(SPOF) 제거, 다중 AZ 배치, 자동화.

2. Domain 2 · 보안 및 규정 준수 (30%)

  • 공동 책임 모델: AWS(클라우드 자체: 물리 보안·하드웨어·하이퍼바이저) vs 고객(클라우드 내부: 데이터 암호화·IAM·게스트 OS 패치·보안 그룹).
  • 보안·감사 서비스: IAM/MFA(인증·최소 권한), CloudTrail(API 감사 로그), AWS Config(구성 변경 추적), Amazon Macie(S3 민감 데이터 탐지), AWS Shield/WAF(DDoS/L7 방어), AWS Artifact(규정 준수 보고서).

3. Domain 3 · 클라우드 기술 및 서비스 (34%)

  • 글로벌 인프라: 리전(Region) > 가용 영역(AZ, 1개 이상 데이터 센터) + 엣지 로케이션(CloudFront·Route 53).
  • 컴퓨팅·스토리지: EC2(IaaS), Lambda(서버리스), S3(객체), Glacier(아카이브), EBS(블록·스냅샷), EFS(공유 파일), Instance Store(임시).
  • DB·네트워킹: RDS/Aurora(관계형), DynamoDB(NoSQL), ElastiCache(인메모리), Athena(S3 SQL), VPC(가상 네트워크), DMS(DB 이관).

4. Domain 4 · 결제, 요금 및 지원 (12%)

  • EC2 요금 모델: On-Demand(단기·무약정), Reserved Instance(1/3년 약정, 3년 All Upfront 최대 할인), Spot(유휴 용량 최대 90% 할인·중단 가능), Dedicated Host(물리 서버·BYOL).
  • 비용 관리·지원: Organizations(통합 결제·볼륨 할인), Cost Explorer(지출 시각화), CUR(상세 사용 보고서), Budgets(예산 알림), Enterprise Support(TAM + Support Concierge).
