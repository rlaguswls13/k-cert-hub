AWS Certified SysOps Administrator - Associate (SOA-C02) 6대 공식 도메인별 비중 및 문항 분포
공식 도메인 공식 비중 수록 문항 수록 비중 단일선택 복수선택 등장 라운드 핵심 출제 토픽

1. 모니터링 · 로깅 · 자동 교정 (Domain 1 · 20%)

# CloudWatch Agent 메모리/프로세스(procstat) 수집
Namespace: CWAgent (mem_used_percent, disk_used_percent)
IAM Role:  CloudWatchAgentServerPolicy 필수
  • StatusCheckFailed_System: 물리 호스트 장애 → CloudWatch Alarm Recover 액션
  • StatusCheckFailed_Instance: OS/커널 장애 → Reboot 액션
  • Metric Filter: 로그 패턴 수치화(알람), DefaultValue=0 미설정 시 무트래픽 INSUFFICIENT_DATA
  • Subscription Filter: 실시간 로그 스트리밍(Lambda, Kinesis, Firehose, OpenSearch)
  • AWS Config + SSM Automation: 비규정 리소스 자동 교정(Auto-Remediation)

2. 고가용성 · 백업 · 연속성 (Domain 2 · 16%)

  • RDS Multi-AZ: 동일 리전 타 AZ 동기 복제(RPO=0), 자동 페일오버, DNS TTL 60초 미만 권장
  • RDS Read Replica: 비동기 복제, 읽기 분산·크로스 리전 DR(수동 Promote)
  • Auto Scaling: Target Tracking(동적 목표 유지), Lifecycle Hook(Wait 상태 처리), Warm Pool(초기화 단축)
  • AWS Backup vs DLM: EFS·RDS·DynamoDB 통합 + Vault Lock(Compliance Mode WORM) = AWS Backup / EBS·AMI 전용 = DLM
  • Route 53: Failover(Active-Passive + Evaluate Target Health), Calculated Health Check(M/N 임계)

3. 배포 · SSM 자동화 · 보안 (Domain 3 & 4 · 34%)

  • CloudFormation: StackSets(멀티계정/리전), Change Set(사전 교체 검토), Stack Policy(업데이트 교체 차단), Drift Detection
  • Systems Manager: Session Manager(포트 22/배스천 제거), Patch Manager(Patch Baseline + Maintenance Window), Run Command(MaxConcurrency/MaxErrors)
  • IAM 유효 권한: Identity Policy ∩ Permission Boundary ∩ SCP (명시적 Deny 최우선)
  • 보안 서비스 구분: GuardDuty(로그 기반 위협 탐지) vs Inspector(CVE 취약점 스캔) vs Access Analyzer(외부 공유 감사)
  • S3 & KMS: Account-level Block Public Access, Cross-Account KMS는 Key Policy + IAM Policy 양쪽 허용

4. 네트워킹 · 비용 · 성능 최적화 (Domain 5 & 6 · 30%)

  • SG vs NACL: SG(Stateful·ENI·Allow만) vs NACL(Stateless·서브넷·번호순 평가·Ephemeral Port 1024-65535 허용 필수)
  • VPC 연결: VPC Peering(비전이적 1:1) vs Transit Gateway(허브 앤 스포크) vs PrivateLink(CIDR 중복 회피 SaaS)
  • VPC 비용 절감: S3/DynamoDB는 무료 Gateway Endpoint(NAT GW 과금 우회), 미사용 EIP 해제
  • CloudFront: S3 직접 차단 OAC, 장애조치 Origin Group, 유료 콘텐츠 Signed URL/Cookie
  • 비용 최적화: Compute Optimizer(+CW Agent 메모리), Compute Savings Plans(EC2+Fargate+Lambda), gp2→gp3(기본 3,000 IOPS), S3 Intelligent-Tiering(≥128KB)
