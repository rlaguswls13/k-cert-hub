AWS DVA-C02 공식 Exam Guide 도메인별 배점 비중 vs 본 RDB 수록 분포
도메인 (Exam Guide) 공식 비중 수록 문항 수록 비율 단일 선택 복수 선택(2개) 공식 PDF Exam Guide 핵심

⚡ Domain 1 — Lambda · DynamoDB · SQS

  • Lambda 동시성: Cold Start 제거 = Provisioned / 최대 상한 제한 = Reserved
  • Lambda 크기/시간: 타임아웃 최대 15분(900초), `/tmp` 512MB~10GB, Layer 최대 5개(합 250MB), 컨테이너 최대 10GB
  • DynamoDB RCU/WCU: RCU는 4KB 올림(Strongly=1 RCU, Eventually=0.5 RCU) / WCU는 1KB 올림
  • LSI vs GSI: LSI(생성 시만, 동일 PK, 10GB 제한) / GSI(언제든 추가, 다른 PK, Eventually Consistent만)
  • SQS 핵심 수치: 기본 메시지 256KB(대용량 Extended Client S3), Long Polling 최대 20초, DelaySeconds 최대 15분

🔐 Domain 2 — IAM · KMS · Cognito · Secrets

  • IAM 평가 순서: Explicit Deny 무조건 우선 → SCP / Permissions Boundary → Allow
  • STS & PassRole: 서드파티 위임 시 sts:ExternalId(Confused Deputy 방지), 서비스에 Role 연결 시 iam:PassRole
  • KMS 봉투 암호화: 4KB 초과 데이터는 GenerateDataKey 후 암호화 데이터 + 암호화된 데이터 키 함께 저장
  • Secrets Manager vs Parameter Store: 자동 로테이션(RDS 등) = Secrets Manager / 무료 단순·계층 설정 = Parameter Store
  • Cognito: 인증/JWT 토큰/Lambda 트리거 = User Pool / 임시 AWS IAM 자격증명 교환 = Identity Pool

🚀 Domain 3 — SAM · Code* · CFN · Beanstalk

  • SAM 카나리 배포: `AutoPublishAlias` + `DeploymentPreference` (`Canary10Percent5Minutes`, `PreTraffic`/`PostTraffic`)
  • CodeBuild/CodeDeploy: `buildspec.yml`(`env.parameter-store`/`secrets-manager`), `appspec.yml`(Lambda/ECS: `BeforeAllowTraffic`/`AfterAllowTraffic`)
  • ECS Role 구분: 이미지 Pull·로그·Secrets 주입 = Task Execution Role / 앱 코드 SDK 호출 = Task Role
  • Elastic Beanstalk: 가장 안전한 무중단/즉시 원복 = Immutable 또는 Clone + Swap URLs; `.platform/hooks/`
  • CloudFormation: 스택 삭제 시 보존 = `DeletionPolicy: Retain/Snapshot` / 업데이트 교체 방지 = `Stack Policy`

🔍 Domain 4 — X-Ray · CloudWatch · 캐시 · 에러

  • X-Ray 구분: 필터 검색 인덱싱 = Annotations / 비인덱싱 디버깅 JSON = Metadata
  • CloudWatch EMF: `PutMetricData` API 호출 없이 `stdout` JSON 로그로 커스텀 메트릭 추출 (1초 정밀도 `StorageResolution: 1`)
  • DAX vs ElastiCache: DAX는 마이크로초 캐시이나 `ConsistentRead=True`는 우회; Redis는 Sorted Sets/PubSub/Multi-AZ 지원
  • API Gateway 에러: 502(Lambda Proxy JSON 스키마 오류, `body` 문자열 누락) / 504(29초 타임아웃) / 403(미배포/경로 오류 `Missing Authentication Token`)
