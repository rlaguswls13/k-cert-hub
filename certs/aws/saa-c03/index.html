AWS SAA-C03 공식 시험 도메인 가중치 vs RDB 수록 분포 및 핵심 키워드
도메인 (Domain) 공식 비중 수록 문항 단일 선택 복수 선택 공식 PDF MIT 은행 대표 핵심 키워드

1. VPC 네트워크 · Load Balancer · 연결

  • PrivateLink vs VPC Peering: CIDR 중복 허용·특정 서비스 단방향 사설 노출 → PrivateLink / 비중복 대량 전송 → VPC Peering / 다수 VPC 허브 → Transit Gateway
  • ALB vs NLB vs GWLB: L7 HTTP/HTTPS 호스트·경로 라우팅 ALB / L4 TCP·UDP 고정 IP·초저지연 NLB / L3 방화벽 인라인 검사(GENEVE) GWLB
  • Gateway vs Interface Endpoint: S3·DynamoDB만 무료 Gateway Endpoint 지원(나머지 AWS 서비스는 유료 PrivateLink Interface Endpoint)
  • NAT Gateway vs IPv4: NAT는 단일 AZ 리소스이므로 AZ별 배치 권장(AZ 장애 격리 및 교차 AZ 전송 비용 제거)

2. 보안 · IAM · 암호화 (Domain 1 · 30%)

  • IAM Permissions Boundary: 개발팀에 Role 생성 위임 시 최대 권한 상한을 강제해 권한 상승 차단
  • Organizations SCP: 멤버 계정 관리자(AdministratorAccess 포함)도 우회 불가한 예방 가드레일(리전 제한 시 글로벌 서비스 NotAction 예외 필수)
  • S3 암호화 4종: 완전 관리·KMS 추적 불필요 SSE-S3 / 감사·키 정책·자동 회전 SSE-KMS / 고객 키 직접 전달 SSE-C / 업로드 전 암호화 CSE
  • ECS Fargate 비밀 주입: 작업 정의 secrets 필드 + Task Execution Role 권한(앱 코드는 Task Role)

3. 복원력 · 디커플링 · DR 전략 (Domain 2 · 26%)

  • DR 4단계 (비용↑ / RTO·RPO↓): Backup & Restore(시간) → Pilot Light(핵심 DB만 복제, 수십분) → Warm Standby(축소 스택 상시 실행, 수분) → Multi-Site Active-Active(실시간)
  • Aurora Global Database: 스토리지 수준 1초 미만 복제 · 계획된 이전은 RPO 0 Switchover, 재해 시 Failover
  • SQS-Lambda 안정성: 부분 실패 격리 ReportBatchItemFailures + Visibility Timeout ≥ 6 × Lambda Timeout
  • Global Accelerator vs CloudFront: TCP/UDP 고정 애니캐스트 IP·DNS 캐시 무관 초고속 장애 조치 → Global Accelerator / HTTP 캐싱 → CloudFront

4. 고성능 & 비용 최적화 (Domain 3 · 4)

  • 스토리지 선택: 블록(단일 AZ·io2 Multi-Attach) EBS / Linux 다중 AZ 공유 NFS EFS / Windows AD·SMB FSx for Windows / 초저지연 ML S3 Express One Zone
  • CloudFront Functions vs Lambda@Edge: 헤더·URL 재작성·캐시 키 정규화(서브ms·초저가) → CloudFront Functions / 외부 네트워크·본문 검사 → Lambda@Edge
  • FinOps 약정 & 요금: 패밀리·Fargate·Lambda 유연 적용 Compute Savings Plans / 중단 허용 Spot / Lambda arm64(Graviton2)
  • 미완료 비용 누수 방지: S3 AbortIncompleteMultipartUpload 수명 주기 · EBS Snapshots Archive + DLM · DynamoDB TTL
