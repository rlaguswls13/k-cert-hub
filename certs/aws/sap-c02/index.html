Domain 1 · 멀티어카운트 & 하이브리드 네트워크 (26%)

  • SCP 핵심 규칙: 권한을 부여(Grant)하지 않고 최대 상한선(Filter)만 제한. Management Account 와 Service-Linked Role 에는 미적용.
  • 동적 조직 신뢰: 조건 키 aws:PrincipalOrgID 로 신규 계정 자동 허용. 태그 강제는 SCP(RequestTag Null Deny) + Tag Policy(허용 값) 결합.
  • TGW + 방화벽: Cross-AZ 비대칭 드롭 방지는 Inspection VPC Attachment의 Appliance Mode 활성화. TGW Inter-Region Peering은 Static Route 만 지원.
  • Direct Connect: 1초 미만 절체 = BFD, 아웃바운드 제어 = AS_PATH Prepending, 인바운드 = Local Preference. MACsec/LAG/다중VIF 는 Dedicated 만 지원.
  • 중첩 CIDR / DNS: M&A 중첩 CIDR = PrivateLink. 중앙 하이브리드 DNS = Shared VPC Resolver Inbound/Outbound 1쌍 + RAM Rule 공유.

Domain 2 · 신규 솔루션 & 글로벌 DR/복원력 (29%)

  • DR 4단계: Backup&Restore(시간) → Pilot Light(앱 정지, 10~30분) → Warm Standby(최소 앱 상시 가동, 수 분) → Active-Active(즉시, 최고 비용).
  • Global Accelerator vs CloudFront: 비HTTP(TCP/UDP), 고정 Anycast IP 2개 방화벽 등록, DNS TTL 우회 30초 내 페일오버 = Global Accelerator.
  • Aurora vs DynamoDB Global: Aurora Managed Planned Failover = RPO 0. DynamoDB Global Tables는 LWW 이므로 엄격한 원자적 쓰기는 Home Region 단일 라우팅.
  • Step Functions: 5분 이상/콜백(.waitForTaskToken)/Saga(Exactly-Once) = Standard, 수천만 S3 병렬 처리 = Distributed Map.
  • 엣지 & 보안: S3+SSE-KMS CDN = OAC(구형 OAI 불가). 메모리 격리 = Nitro Enclaves + KMS Attestation. AZ 대피 = ARC Zonal Shift.

Domain 3 · 기존 솔루션 성능·비용·운영 개선 (25%)

  • S3 튜닝: 전사 누수 진단 = Storage Lens, 20억 객체 소급 암호화 = Inventory + Batch Operations + Bucket Key(KMS 99%↓), 단일 AZ ML = Express One Zone.
  • EBS / EFS / FSx: EBS는 인스턴스 EBS 대역폭 상한 먼저 확인(gp3 최대 16K IOPS/1000 MB/s). EFS 크레딧 고갈 = Elastic Throughput. HPC = FSx Lustre, 다중프로토콜 = FSx ONTAP.
  • 네트워크 & FinOps: Private Subnet S3/DDB 비용 절감 = 무료 Gateway VPC Endpoint + AZ별 NAT GW. OS 메모리 사이징 = CW Agent + Compute Optimizer.
  • 서버리스/데이터베이스: Java 콜드 스타트 = Lambda SnapStart. Athena 스캔 90%↓ = 128~512MB Parquet(Snappy) + Partition Projection. Aurora I/O > 25% = I/O-Optimized.
  • 관측/전송: 무API 커스텀 메트릭 = CloudWatch EMF, Top-N = Contributor Insights. NAS→S3 = DataSync, 외부 SFTP = Transfer Family.

Domain 4 · 워크로드 마이그레이션 & 현대화 (20%)

  • 7Rs 선택: 무수정 VM/물리 Lift&Shift = Rehost (AWS MGN). vSphere L2 IP 보존 = Relocate (VMware Cloud HCX). SaaS 대체 = Repurchase.
  • DB 전환 분기: 이기종(Oracle→Aurora PG) = SCT + DMS(Full Load+CDC, 인덱스/FK 일시 해제). 동종(MySQL→Aurora MySQL) = Percona XtraBackup + Binlog 네이티브 복제.
  • 대역폭 계산 & 오프라인: WAN 100 Mbps로 수주 내 수백 TB = Snowball Edge (오프라인 초기 적재) + DataSync (온라인 델타).
  • 모놀리스 점진 해체: Strangler Fig(ALB Weighted / API GW / CloudFront 경로 전환 + CDC/Outbox 데이터 분리), 멀티어카운트 서비스 망 = VPC Lattice / Refactor Spaces.
  • 컨테이너 & 배치: 코드 수정 없이 Java/IIS 컨테이너화 = App2Container + Fargate. K8s CRD = EKS. 15분/10GB 초과 배치 = AWS Batch.
